# نظام نحت العقارية (Naht ERP & Public Website)

هذا هو الإصدار الجديد والمطور بالكامل لنظام "نحت الأصول العقارية"، مبني باستخدام أحدث تقنيات الويب كمنصة شاملة (Full-Stack).

## التقنيات المستخدمة
- **إطار العمل:** Next.js (App Router)
- **لغة البرمجة:** TypeScript
- **التصميم:** Tailwind CSS v4 (مع دعم كامل للغة العربية RTL)
- **قاعدة البيانات:** SQLite (مرحلة التطوير الأولى) -> سيتم الترقية لـ PostgreSQL
- **ORM:** Prisma
- **نظام المصادقة:** NextAuth.js

## طريقة التشغيل المحلي (Development)

1. تأكد من تثبيت [Node.js](https://nodejs.org/en) (الإصدار 18 فما فوق).
2. افتح سطر الأوامر (Terminal) داخل مجلد `6-naht-platform`.
3. قم بتثبيت الحزم (إذا لم تكن مثبتة):
   ```bash
   npm install
   ```
4. قم بتهيئة قاعدة البيانات الأولية:
   ```bash
   npx prisma db push
   ```
5. لتشغيل النظام في بيئة التطوير:
   ```bash
   npm run dev
   ```
6. افتح المتصفح على الرابط: `http://localhost:3000`
